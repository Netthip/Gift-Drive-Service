# เคสตัวอย่าง (ดัดแปลง ไม่ใช่แชทจริง): DMK → ที่พักย่านเพชรบุรี ครอบครัว 8 คน

> repo นี้เป็น private แล้ว แต่ยังห้ามใส่ชื่อลูกค้า แชทจริง เบอร์โทร สลิป QR หรือข้อมูลจองรายบุคคล (Issue #1)

## ข้อความลูกค้า (ตัวอย่างแบบตัวเต็ม 繁體)
1. 請問從 DMK airport 去 airbnb（Phetchaburi 一帶）
2. 6個大人 2個 baby
3. 2月9號
4. 6個 handcarry（7kg） 2個 大行李（20kg）

## จุดที่แอปแปลอัตโนมัติพลาด
| ข้อความ | แปลอัตโนมัติ | ความหมายจริง |
|---|---|---|
| 請問從A去B | "ไปได้อย่างไรบ้าง" | ขอบริการรับและราคา จาก A ไป B |
| baby | "เด็กเล็ก" | ทารก → ต้องถามคาร์ซีท และนับเป็นผู้โดยสาร |
| 大行李（20kg） | ถูก | บอกแค่น้ำหนัก ไม่บอกขนาดนิ้ว → ต้องถาม |

## ร่างคำตอบ (简体, ไม่มีอีโมจิ) — ขอข้อมูลและแจ้งข้อจำกัดตามจริง ยังไม่เสนอราคา
```
您好，谢谢您的询问。
我们的车是 MG4 电动车，每辆车建议最多坐3位乘客。
您一共8位（6位大人和2位宝宝），一辆车坐不下，我需要先确认能否安排更多车辆。
麻烦您告诉我：
1. 航班号码和抵达时间
2. 两个大行李大约几寸

确认后我会尽快回复您。
```
